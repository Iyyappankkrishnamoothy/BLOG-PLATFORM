# 📝 Blog-Platform

A full-stack **Blog Platform** developed as part of the **Thiranex Internship Program**. This project allows users to create, read, update, and delete blog posts through a clean and responsive web interface while demonstrating core full-stack web development concepts.

---

## 📌 Project Overview

The Blog Platform enables users to publish blog posts, edit existing content, delete unwanted posts, and browse articles efficiently. The project focuses on implementing CRUD operations, REST APIs, frontend-backend communication, and responsive UI design.

---

## ✨ Features

### 👤 User Features

- User Registration
- User Login & Logout
- Create Blog Posts
- View All Blog Posts
- Read Individual Posts
- Edit Existing Posts
- Delete Blog Posts
- Search Posts
- Responsive User Interface

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/your-username/blog-platform.git
```

### Navigate to the Project

```bash
cd blog-platform
```

### Install Dependencies

```bash
npm install
```

### Start the Server

```bash
npm start
```

### Open the Application

```
http://localhost:3000
```
